# frontend/CLAUDE.md — React / Vite / TypeScript 규칙

> 루트 `../CLAUDE.md`(불변 원칙·커밋 규칙)와 함께 적용된다. 여기선 프론트 영역만 좁힌다.
> 이 문서는 **시작 셋팅 기준**이며, 특정 화면/기능 구현 상세는 담지 않는다.

## 스택 · 실행

- React 19 + TypeScript + **Vite 6** SPA. `type: module`.
- 개발 서버 `:3000`, `/api` → 백엔드 `:8080` 프록시(`vite.config.ts`). 프론트는 항상
  **상대경로 `/api/...`** 로만 호출한다(백엔드 호스트를 하드코딩하지 않는다 — dev는 vite 프록시,
  배포는 nginx가 프록시).

```bash
npm install
npm run dev        # :3000
npm run build      # tsc --noEmit(타입체크) → vite build → dist/
npm run preview    # 빌드 결과 확인
npm run lint       # eslint 정적 분석 (자동수정: npm run lint:fix)
```

## 규칙

- **타입 안전**: `build`가 `tsc --noEmit`로 타입체크를 강제한다. `any`·`@ts-ignore`로 뚫지 말 것.
  타입 에러를 남긴 채 커밋하지 않는다(빌드가 곧 게이트).
- **비밀 반입 금지**: LLM API 키 등 어떤 비밀도 프론트 번들에 넣지 않는다. 모든 LLM 호출은
  백엔드 경유(BYO key는 서버에만).
- **불변 원칙의 프론트 표현**:
  - *근거 없는 생성 금지* → 조회 답변은 근거(citation) 링크와 함께 렌더. 근거 없는 문장을
    단정처럼 보이게 하지 않는다.
  - *승인 게이트* → 저장 결과는 자동 반영이 아니라 **검토 대기함**을 거쳐 사용자가 승인/반려.
    UI가 "이미 저장됨"처럼 오인시키지 않는다.
  - *조용한 실패 금지* → 로딩/실패/부분성공 상태를 항상 노출(빈 화면·무한 스피너 금지).
- **조회는 SSE 스트리밍**: `POST /api/query`는 서버-전송 이벤트로 답변이 흘러온다. 스트림
  중단·재연결·중복 이벤트를 방어한다(누적 렌더 시 중복 제거).
- **의존성 최소**: 상태관리·데이터패칭 라이브러리는 필요해질 때 도입하고, 도입 시 근거를 남긴다
  (지금은 표준 템플릿 유지). 무분별한 패키지 추가 금지.

## 코딩 규칙 (TS / React)

교과서식 일반론이 아니라 **이 프로젝트에 묶은** 규칙이다. 새 코드는 아래를 따른다.

### 타입

- **strict 준수.** `any`·`@ts-ignore` 금지(빌드 게이트). 불가피하면 `unknown` + 좁히기(type guard).
- **API 계약을 타입으로.** 서버 응답/요청에 명시 인터페이스를 두고, 계약이 바뀌면 타입부터 고친다.
  `as` 단언은 최후수단.

### 컴포넌트 설계 (SRP/컴포지션)

- **함수형 컴포넌트 + 훅.** 한 컴포넌트 한 책임 — **표시(presentational)와 데이터 페칭/로직을
  분리**하고, 로직은 **커스텀 훅**(`useXxx`)으로 뺀다.
- **컴포지션 우선.** prop drilling이 깊어지면 children 합성 또는 Context. 전역 상태 라이브러리는
  필요해질 때 근거를 남기고 도입(지금은 표준 템플릿).
- 큰 컴포넌트는 쪼갠다. JSX 안 삼항 중첩보다 변수/작은 컴포넌트로.

### 상태 · 이펙트

- **파생 상태를 state로 두지 않는다** — 렌더 중 계산. `useEffect`는 **외부 동기화 전용**
  (계산·파생에 쓰지 않는다).
- **정리(cleanup) 필수.** fetch는 `AbortController`, SSE는 close. 언마운트 후 setState 금지.
- **불변 업데이트.** state/props 직접 변이 금지(스프레드/불변 패턴).

### 데이터 페칭 · 불변 원칙의 프론트 표현

- **`/api` 상대경로만**(호스트 하드코딩 금지). 로딩·에러·부분성공 상태를 **항상 노출**
  (빈 화면·무한 스피너 금지 = 조용한 실패 금지).
- **근거 없는 단정 UI 금지** — 조회 답변은 citation과 함께, 근거 없으면 "기록 없음"으로 표시.
- **승인 게이트 표현** — 저장 결과를 "이미 저장됨"처럼 오인시키지 않는다(검토 대기 경유).
- **SSE**(`POST /api/query`): 스트림 중단·재연결·중복 이벤트 방어(누적 렌더 시 중복 제거).

### 순수성 · 스타일

- **렌더는 순수하게.** 부수효과는 이벤트 핸들러/이펙트에서만.
- 컴포넌트 `PascalCase`, 훅 `useX`, 파일 1개 = 컴포넌트 1개 지향. 매직 문자열/숫자는 상수화.
- **비밀 반입 금지**(번들은 공개물). 포맷은 **prettier**가 강제 — 손으로 맞추지 말고 `npm run format`.
- **정적 분석은 eslint가 강제** — `npm run lint`(자동수정 `npm run lint:fix`). 역할 분리: **eslint=규칙
  검사**(타입 우회·훅 규칙 등), **prettier=포맷**. lint 경고를 남긴 채 커밋하지 않는다.
- **무분별한 패키지 추가 금지** — 의존성은 비용이다(번들·보안·유지보수).

## 배포 (추후)

배포 시 `npm run build` 산출물(`dist/`)을 nginx가 서빙한다(`../nginx/CLAUDE.md`). 프론트가
API 호스트를 하드코딩하지 않는 한 dev/배포가 동일 코드로 동작한다. 배포 세부는 추후 확정.
