# backend/CLAUDE.md — Spring Boot / Java 규칙

> 루트 `../CLAUDE.md`(불변 원칙·커밋 규칙)와 함께 적용된다. 여기선 백엔드 영역만 좁힌다.
> 이 문서는 **시작 셋팅 기준**이며, 특정 기능 구현 상세는 담지 않는다.

## 스택 · 실행

- Spring Boot 4.0 / **Java 25**(Gradle toolchain). **모듈러 모놀리스**(`com.recall.*`).
- 데이터: JPA + PostgreSQL 17 + pgvector. 스키마는 **Flyway 소유**.

```bash
./gradlew bootRun     # :8080  (Windows: gradlew.bat)
./gradlew build       # 컴파일 + 테스트
./gradlew test        # 전체 테스트
./gradlew test --tests 'com.recall.SomeTest.method'   # 단일 테스트
```

## 구조 원칙

- **패키지 = 모듈 경계**. 모듈 간 결합은 서비스 빈 **생성자 주입**으로만. 순환/교차 참조를 늘리지
  않는다. 새 기능은 새 패키지(모듈)로 시작하는 걸 우선 검토.
- **경로 성격을 지킨다**:
  - *저장 경로* = 비동기(`@Async` 잡). 원문 커밋만 동기(유실 금지 앵커), 이후 무거운 처리는 잡으로.
  - *조회 경로* = 동기 **SSE**(`SseEmitter`). LLM 호출을 최소로 유지해 동기로 둔다.
- **불변 원칙의 백엔드 표현**:
  - *마스킹 우선* — 원문이 외부 LLM/인덱스/로그로 나가기 전에 값 마스킹. 이 순서를 바꾸지 않는다.
  - *승인 게이트* — 저장·추출 코드는 **memory에 직접 쓰지 않는다**. 오직 검토 승인 지점에서만 반영.
  - *삭제 대신 상태 보존* — 레코드 삭제 대신 status 전이. 충돌은 자동 덮어쓰기 금지.
  - *결정론 단계에 LLM 금지* — 플래너/검색/가중치는 결정적으로. LLM은 분류·추출·판정·리랭크·답변만.

## 데이터 / 스키마

- **스키마 변경은 Flyway 새 마이그레이션(`src/main/resources/db/migration/V__*.sql`)으로만.**
  `ddl-auto=none`이므로 엔티티로 스키마를 만들지 않는다. 기존 마이그레이션 파일은 수정하지 않는다
  (되돌릴 수 없음 — 항상 새 버전 추가).
- **단일 사용자 전제** — `user` 테이블/`user_id` 컬럼을 만들지 않는다(격리 = 사용자당 DB 1개).
- pgvector는 **용도별 이중 임베딩**을 쓴다("무엇을 임베딩하나"가 연관성의 절반). 원문 캡처는
  **검색 인덱싱 대상이 아니라 근거**다.

## 설정 · 비밀

- LLM은 외부 API·**BYO key**(`recall.llm.*`, `@ConfigurationProperties`). 강/저가/임베딩 모델을
  분리 설정(비용 레버). 키·접속정보는 `.env`/환경변수로만, 커밋 금지.
- CORS는 로컬 개발(vite `:3000`)에서만 관여. 배포는 nginx가 동일 오리진으로 프록시.
