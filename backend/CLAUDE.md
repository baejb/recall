# backend/CLAUDE.md — Spring Boot / Java 규칙

> 루트 `../CLAUDE.md`(불변 원칙·커밋 규칙)와 함께 적용된다. 여기선 백엔드 영역만 좁힌다.
> 이 문서는 **시작 셋팅 기준**이며, 특정 기능 구현 상세는 담지 않는다.

## 스택 · 실행

- Spring Boot 4.0 / **Java 25**(Gradle toolchain). **모듈러 모놀리스**(`com.recall.*`).
- 데이터: JPA + PostgreSQL 17 + pgvector. 스키마는 **Flyway 소유**.

```bash
./gradlew bootRun     # :8080  (Windows: gradlew.bat)
./gradlew build       # 컴파일 + 테스트
./gradlew test        # 전체 테스트
./gradlew test --tests 'com.recall.SomeTest.method'   # 단일 테스트
```

## 구조 원칙

- **패키지 = 모듈 경계**. 모듈 간 결합은 서비스 빈 **생성자 주입**으로만. 순환/교차 참조를 늘리지
  않는다. 새 기능은 새 패키지(모듈)로 시작하는 걸 우선 검토.
- **경로 성격을 지킨다**:
  - *저장 경로* = 비동기(`@Async` 잡). 원문 커밋만 동기(유실 금지 앵커), 이후 무거운 처리는 잡으로.
  - *조회 경로* = 동기 **SSE**(`SseEmitter`). LLM 호출을 최소로 유지해 동기로 둔다.
- **불변 원칙의 백엔드 표현**:
  - *마스킹 우선* — 원문이 외부 LLM/인덱스/로그로 나가기 전에 값 마스킹. 이 순서를 바꾸지 않는다.
  - *승인 게이트* — 저장·추출 코드는 **memory에 직접 쓰지 않는다**. 오직 검토 승인 지점에서만 반영.
  - *삭제 대신 상태 보존* — 레코드 삭제 대신 status 전이. 충돌은 자동 덮어쓰기 금지.
  - *결정론 단계에 LLM 금지* — 플래너/검색/가중치는 결정적으로. LLM은 분류·추출·판정·리랭크·답변만.

## 아키텍처 · 확장 규칙

> 패턴은 **실용 계층형 모듈러 모놀리스 + LLM/임베딩 경계에만 경량 헥사고날**. 선택 이유·판단
> 기준·모듈 경계·분담은 `docs/architecture.md`. 여기선 **강제 규칙**만 둔다.

- **포트는 "교체가 실제로 필요한 경계"에만** — `LlmClient`·`EmbeddingClient`만 인터페이스로 열고
  주입한다. 그 외(memory·review·search·capture 등)는 구체 클래스 + JPA. `XxxService`에
  `XxxServiceImpl` 껍데기를 만들지 않는다(YAGNI).
- **유형(type) 변동은 전략 SPI로만** — 파이프라인 단계별 유형 차이는 `Map<MemoryType, XxxStrategy>`
  (자가 등록 `supports(): MemoryType`)로 주입한다. **공유 코드에 `switch(MemoryType)` 금지**(새 유형
  마다 switch를 고치게 되면 OCP 붕괴).
- **SPI는 진짜 변동 축에** — 추출(S2)·검색표현(R)·판정(S4)은 유형축. **답변(A)은 유형×intent** 라
  공유 Composer가 intent를 처리하고 유형 전략은 근거·필드만 기여한다(순수 per-type 포매터 금지).
- **선택적 단계는 plan 플래그로** — `if(type==…)` 분기 대신 plan(`use_reranker`·`raw_search_required`
  등)이 단계를 켜고 끈다.
- **임베딩은 제네릭 키 테이블** `memory_embedding(kind, vector)` — 유형별 벡터 컬럼을 `memory`에 박지
  않는다(새 표현 = 스키마 변경이 아니라 행 추가).

## 데이터 / 스키마

- **스키마 변경은 Flyway 새 마이그레이션(`src/main/resources/db/migration/V__*.sql`)으로만.**
  `ddl-auto=none`이므로 엔티티로 스키마를 만들지 않는다. 기존 마이그레이션 파일은 수정하지 않는다
  (되돌릴 수 없음 — 항상 새 버전 추가).
- **단일 사용자 전제** — `user` 테이블/`user_id` 컬럼을 만들지 않는다(격리 = 사용자당 DB 1개).
- pgvector는 **용도별 이중 임베딩**을 쓴다("무엇을 임베딩하나"가 연관성의 절반). 원문 캡처는
  **검색 인덱싱 대상이 아니라 근거**다.

## 설정 · 비밀

- LLM은 외부 API·**BYO key**(`recall.llm.*`, `@ConfigurationProperties`). 강/저가/임베딩 모델을
  분리 설정(비용 레버). 키의 출처는 둘: (1) `.env`/환경변수(부팅 기본), (2) 사용자가 UI로 입력해
  DB에 저장한 값(단일 사용자). 어느 경우든 **키 파일·값은 커밋 금지.**
- CORS는 로컬 개발(vite `:3000`)에서만 관여. 배포는 nginx가 동일 오리진으로 프록시.

### LLM/비밀 시큐어코딩 (필수)

LLM provider 키·자격증명을 다루는 코드는 아래를 **반드시** 지킨다(자격증명은 사용자 콘텐츠가
아니므로 마스킹-우선 원칙과 **별도로** 얹는다). 위반은 🔴 치명(자격증명 유출).

- **저장 시 암호화(at-rest)** — DB에 넣는 provider 키는 **평문 금지**. 애플리케이션 레벨
  **AES-GCM 암호화**, 마스터키는 env `RECALL_SECRET_KEY`. DB 덤프/백업으로 키가 새지 않게 한다.
- **fail-closed** — `RECALL_SECRET_KEY` 미설정 시 키의 DB 영속을 **거부**한다(조용히 평문 저장
  금지). 이 경우 env로 주입된 키로만 동작한다.
- **로그 금지** — 키 값을 로그·예외 메시지·스택에 남기지 않는다(마스킹). `toString()`에 키를 넣지
  않는다.
- **클라이언트 반환 금지** — 설정 API는 `apiKeyConfigured`(불리언)·마스킹 값만 반환. 평문/전체
  키를 프론트로 내려보내지 않는다.
- **전송 최소화** — 키는 **의도한 provider로만**(HTTPS Authorization 헤더) 보낸다. 인덱스·로그·
  서드파티로 나가지 않는다.
- **base-url 검증** — provider base-url 오버라이드는 **https 스킴만** 허용(BYO 자기 인스턴스
  전제, SSRF 여지 축소).
- **capability 검증** — provider가 해당 역할(chat/embedding)을 지원할 때만 허용(경계에서 거부).

## 코딩 규칙 (Java)

교과서식 일반론이 아니라 **이 프로젝트에 묶은** 규칙이다. 새 코드는 아래를 따른다.

### 설계 원칙 (SOLID을 Recall에 적용)

- **SRP — 한 클래스 한 책임.** PRD 파이프라인 단계(분류 C · 플래너 P · 검색 R · 가중치 W ·
  리랭크 RR · 답변 A · 마스킹 M0 · 추출 S2 · 판정 S4)는 **단계별 클래스 하나**로. 컨트롤러는
  HTTP 변환만, 오케스트레이션은 서비스, 영속은 리포지토리. "이 클래스가 하는 일"을 한 문장으로
  말 못 하면 쪼갠다.
- **OCP/DIP — 교체가 실제로 필요한 경계만 인터페이스.** 모델 백엔드(LLM/임베딩)처럼 PRD가
  "교체 가능"이라 명시한 곳만 인터페이스로 열고 구현을 주입한다. 그 외엔 인터페이스를 만들지
  않는다(YAGNI). **결정론 단계(P/R/W)는 인터페이스보다 순수 로직**으로 — 재현·감사 우선.
- **LSP — 구현체는 계약을 지킨다.** 폴백 구현(graceful degradation: RR 실패 시 W 결과 그대로
  등)도 같은 널/예외/범위 계약을 지켜 상위가 분기 없이 쓴다.
- **ISP — 좁은 역할 인터페이스.** 큰 만능 인터페이스 대신 필요한 메서드만.

### 계층 · 의존 방향

- `controller → service → repository`. **역방향/횡단 호출 금지.** 도메인 서비스는 웹/영속
  세부(HTTP, JPA 애노테이션)를 모른다.
- **패키지 = 모듈 경계.** 다른 모듈은 그 모듈의 **public 서비스**로만 접근. 내부 클래스·엔티티를
  모듈 밖으로 노출하지 않는다. 순환 의존 금지.

### 의존성 주입 · 불변

- **생성자 주입만.** 필드 `@Autowired` 금지. 주입 필드는 `final`. Lombok 없이 명시적으로.
- **불변 우선.** DTO는 `record`. 밖으로 주는 컬렉션은 `List.copyOf` 등 방어적. 세터 남발 금지.
- **엔티티 ↔ DTO 분리.** JPA 엔티티를 컨트롤러 응답/요청 바디로 직접 쓰지 않는다.

### 예외 · 실패 처리

- **도메인 예외 타입 + 전역 핸들러(`@RestControllerAdvice`)** 로 일관 변환. 컨트롤러마다
  try-catch 흩뿌리지 않는다.
- **조용한 실패 금지(불변 원칙).** 예외를 삼키는 빈 catch 금지. 실패는 상태(`FAILED_AT_STAGE`
  등)·로그로 드러낸다. 의도적으로 무시한다면 **이유를 주석**으로.
- 예상된 부재는 `Optional` 반환(널 전파 차단). 파라미터엔 `Optional`을 쓰지 않는다.

### 검증 · 매직넘버

- 입력 검증은 **경계**(컨트롤러 DTO `@Valid`)에서. 도메인 내부는 검증됐다고 가정.
- **매직넘버 금지.** 임계값·가중치(`τ_conf`·`τ_recall`·`τ_sim`·`τ_ans`·채널 가중치·boost/penalty)는
  하드코딩하지 않고 **상수 또는 `@ConfigurationProperties`** 로 뺀다. 값의 근거는 라벨셋 fit
  (PRD 품질 기준·Eval 계획) — 바꾸면 커밋/Decision Log에 근거를 남긴다.

### 테스트 (TDD 우선)

- **테스트부터 쓴다(red → green → refactor).** 새 PRD 파이프라인 단계·버그 수정은 실패하는
  테스트를 먼저 만들고 통과시킨다. 구현 뒤에 테스트를 끼워 맞추지 않는다.
- **단계 성격에 맞게 검증한다**: 결정론 단계(M0·P·R·W)는 순수 함수 단위테스트(같은 입력=같은
  출력), 확률적 단계(C·RR·A·S2·S3·S4)는 PRD Eval 케이스(허용 범위 판정)로 건다.
- **🔴 치명 케이스는 회귀 테스트 필수** — 마스킹 유출·충돌 자동 덮어쓰기·근거 없는 생성은
  케이스를 항상 유지하고 병합 게이트로 막는다.
- 실행·작성 세부는 `test` 스킬을 따른다.

### 테스트 용이성 · 스타일

- **결정론 단계는 순수 함수처럼**(부작용·랜덤·시계 의존 최소) 짜서 같은 입력=같은 출력으로
  테스트·재현 가능하게. 시간/랜덤/외부 호출이 필요하면 주입(`Clock` 등)한다.
- 메서드는 작게, 한 가지 일. 깊은 중첩보다 **early return**.
- **import는 파일 상단에 선언한다.** 코드 본문에서 FQN(`java.util.Set`, `java.util.Collections` 등)을
  직접 쓰지 않는다(가독성·spotless 정합).
- 로깅은 **slf4j**. `System.out/err.print` 금지(pre-commit이 차단).
- 포맷은 **spotless(google-java-format AOSP)** 가 강제 — 손으로 맞추지 말고 `./gradlew spotlessApply`.
